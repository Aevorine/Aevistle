# Aevistle

**تذكيرات بريدية مجدولة تصل فعلًا في موعدها.**

اكتب الرسالة مرة واحدة — مع ما تشاء من ملفات أو صور أو ملفات مضغوطة — ويتكفّل
Aevistle بإرسالها في وقتها، حتى والنافذة مغلقة. مرة واحدة، أو كل يوم عمل في
09:00، أو في أول كل شهر، أو وفق أي تعبير cron تريده. Windows وأندرويد، بلا
حساب، وبلا خادم، وبلا أي تتبّع.

*تقرير الأسبوع كل جمعة. الفاتورة في أول الشهر. رسالة عيد الميلاد عند منتصف
الليل وأنت نائم.*

## لماذا وُجد هذا البرنامج

كل برامج البريد تعرف كيف ترسل رسالة، لكن يكاد لا يوجد بينها ما يَعِدك بأن
الرسالة ستنطلق الثلاثاء القادم في 07:00 ومعها المرفق الصحيح — سواء تذكّرت أنت
أم لا، وسواء كان التطبيق مفتوحًا أم لا.

Aevistle يفي بهذا الوعد أولًا. لا حاجة لإنشاء حساب — فهو يتصل بخادم SMTP الذي
تملكه أصلًا (Gmail أو Outlook أو QQ أو 163 أو خادم شركتك) ثم يرسل. الاستقبال
موجود أيضًا، لكنه يبقى بعيدًا عن طريقك حتى تُفعّله بنفسك: وجّه حسابًا إلى خادم
IMAP الخاص به، فيجمع لك Aevistle صندوق وارد موحّدًا، ويستخرج رموز التحقق
وروابط تسجيل الدخول تلقائيًا، ويترك كل ما عداها كما هو دون أي تدخل.

**يستخدمه الناس في** إرسال تقرير أسبوعي كل جمعة الساعة 17:00 · تذكير صف دراسي بواجب في الليلة السابقة · إرسال فاتورة في اليوم الأول من كل شهر · بعث تهنئة عيد ميلاد عند منتصف الليل أثناء النوم · التذكير بالإيجار كل 30 يومًا · جدولة رسالة متابعة تصل صباحًا بدل الثانية فجرًا · الحصول على رمز تحقق فور وصوله دون الحاجة إلى تبديل التطبيق.

**قد لا يناسبك إن** كنت تريد برنامج بريد متكاملًا — بلا إدارة مجلدات، وبلا مزامنة IDLE الفورية، وبلا حذف من جهة الخادم، وذلك عن قصد — أو أداة تسويق ببكسلات تتبّع ومعدلات فتح، أو خدمة مستضافة تواصل الإرسال وأجهزتك مطفأة. يرسل Aevistle ويقرأ من *جهازك* عبر *صندوقك* — ولهذا بالذات لا يحتاج حسابًا خاصًا به ولا يجمع شيئًا.

## ماذا يفعل

| | |
|---|---|
| 📮 **أرسل الآن أو لاحقًا** | الزرّان المهمّان مثبّتان أسفل شاشة الكتابة مهما كان حجم النافذة، فلا تحتاج إلى التمرير كي ترسل. |
| 📥 **صندوق وارد اختياري** | فعِّل IMAP لحساب ما، فيملأ Aevistle بيانات الخادم بنفسه، ويختبرها قبل الحفظ، ثم يجمع رسائل كل الحسابات في صندوق واحد — عرض موحّد أو مُرشَّح على حساب بعينه، ويُفحص وفق الفترة التي تختارها. فتح الرسالة يمنحها النافذة كاملة، و`Esc` يعود خطوة إلى الوراء؛ `J`/`K` للتنقل بين الرسائل و`Ctrl+F` للبحث داخل الرسالة. المرفقات الواردة تُعرض في مكانها — صور وPDF ونصوص — أو تُفتح ببرنامج النظام، أو تُحفظ حيث تشاء، أو تُظهَر في مدير الملفات. تبقى الصور البعيدة محجوبة، وكل رابط يمرّ عبر تأكيد يعرض الوجهة الحقيقية. |
| 🔑 **رموز التحقق في شاشة خاصة بها** | تُستخرج رموز التحقق وروابط الدخول تلقائيًا من البريد الوارد وتُجمع في شاشة مستقلة: المرسِل والموضوع ووقت الوصول والرمز نفسه بحجم يُقرأ من نظرة واحدة. انقر أي موضع في البطاقة لنسخه. يحمل الإشعار الرمز نفسه فلا تحتاج إلى فتح شيء، ويبقى السجل بعد حذف الرسالة الأصلية. |
| ⚡ **إرسال دفعي متكرر** | يمكن لعملية إرسال مجدولة واحدة أن ترسل الرسالة نفسها عدة مرات متتالية، بوتيرة تحددها أنت بالميلي ثانية — لاختبار تحمّل مسار الإرسال الخاص بك، لا لإزعاج أحد. |
| 📎 **أي مرفق، وصور داخل نص الرسالة** | مستندات وصور وملفات مضغوطة — أي شيء ضمن حد مزوّدك. الصق صورة منسوخة مباشرة داخل الرسالة لتُدرَج مضمّنة؛ يمكن أيضًا تحويل أي صورة مرفقة من ملف مرفق إلى صورة تظهر داخل الرسالة، والعكس. يعرض Aevistle الحجم الفعلي أثناء الإرسال، لأن base64 يحوّل ملفًا بحجم 20 ميغابايت إلى 27 ميغابايت، وهذا سبب رفض مرفقات «ضمن الحد». |
| 🖼️ **صور تراها فعلاً** | كل صورة في الرسالة — مضمّنة في النص، أو مرفقة كملف، أو واردة إلى صندوقك — تظهر كصورة مصغّرة يمكن النظر إليها بدل اسم ملف يحتاج إلى تخمين. نقرة واحدة تفتح العارض بملء الشاشة: عجلة الفأرة للتكبير، والسحب للتحريك، ونقرة مزدوجة للتبديل بين «ملء الإطار» والحجم الأصلي، وتدوير ربع دورة في الاتجاهين، وانعكاس أفقي أو رأسي، والأسهم للتنقل بين بقية صور الرسالة، مع عرض الأبعاد بالبكسل وحجم الملف والصيغة قبل حفظها على القرص أو نسخها إلى الحافظة. ويغلق `Esc` الصورة وحدها دون ما تحتها. |
| 📆 **تقويم عمل يُظهر أثره** | العطلات الرسمية، وعطلة نهاية الأسبوع التي تحدّدها بنفسك، وأيام العمل التعويضية — مع شبكة شهرية تبدّل اليوم بنقرة، ونقاط انطلاق بنقرة واحدة لستة بلدان، وعدد التذكيرات الواقعة في كل تاريخ، مملوءًا حين يكون التقويم هو من نقلها. |
| 📊 **ترى أنها أُرسلت فعلًا** | كل صف يعرض آخر إرسال، وهل نجح، وكم مرة نُفِّذ. التذكيرات لمرة واحدة تنتقل إلى تبويب «المكتملة» بعد انتهائها بدل أن تبقى في القائمة وكأنها ما زالت تنتظر. |
| 🗑️ **حذف له معنى** | إجراءان منفصلان لأنهما طلبان مختلفان: الإزالة من Aevistle (قابلة للتراجع من سلة تحفظها سبعة أيام) أو الحذف من صندوق البريد على الخادم (غير قابل للتراجع، ويقول ذلك صراحة). |
| ✍️ **وضع التركيز** | `F9` يخفي كل شيء عدا الرسالة ويمنحها النافذة بأكملها، و`Esc` يعيد الباقي. على التسمية عدّاد للأحرف وللبايتات — الحرف الصيني ثلاثة بايتات، والبايت هو ما يحسبه حدّ مزوّدك. |
| 🔁 **تكرار حقيقي** | مرة · كل N دقيقة · يوميًا · أسبوعيًا في أيام تختارها · شهريًا (بقاعدة معقولة ليوم 31) · سنويًا · تعبير cron كامل بخمسة حقول. |
| 🔒 **لقطات للمرفقات** | جدوِل تذكيرًا للشهر القادم، ويحتفظ Aevistle بنسخته الخاصة من الملفات، فلا يؤدي نقل الأصل أو إعادة تسميته إلى عطب صامت. |
| ⏰ **يعمل والنافذة مغلقة** | على Windows تبقى عملية في شريط النظام، وعلى أندرويد منبّه دقيق مع WorkManager. إغلاق النافذة لا يلغي تذكيراتك. |
| 🌙 **سياسة التعويض** | نام الحاسوب ففاتت ثلاثة مواعيد؟ اختر إرسالًا تعويضيًا واحدًا أو التخطي. لن تستيقظ على ثلاث رسائل متطابقة. |
| 🎲 **تشتيت التوقيت وتخطي العطلة** | وزّع الإرسال داخل نافذة زمنية كي لا يقرأ المزوّد الدفعة على أنها بريد مزعج، وأجّل ما يقع في العطلة إلى الاثنين. |
| 🔐 **كلمات المرور تبقى مكانها** | يشفّرها النظام: DPAPI على Windows، ومخزن المفاتيح المدعوم بالعتاد على أندرويد. لا تدخل ملف الإعدادات ولا أي ملف تصدير. |
| 📂 **مجلدك وقواعدك** | يسأل Aevistle عن مكان حفظ بياناتك عند أول تشغيل، ويمكن تغييره لاحقًا من **الإعدادات ← مجلد البيانات**. ينقل ما هو موجود **ويصحّح المسارات المحفوظة داخل الجدولات القائمة**، فيظل التذكير الذي أنشأته الشهر الماضي قادرًا على إيجاد مرفقه. |
| 🔌 **اتصالات تنجح فعلاً** | المنفذ ونمط التشفير غير متطابقين؟ يجرّب Aevistle التركيبة الأخرى التي يقبلها مزوّدك بدل الفشل برسالة «Unexpected socket close»، ثم يعرض حفظ ما نجح. ولكل محاولة حدّ زمني، فزر الاختبار يعود بنتيجة دائمًا. |
| 🩺 **يقول ما حدث** | الاختبار الناجح يذكر نقطة الاتصال التي نجحت وزمن الذهاب والعودة؛ والفاشل يسمّي السبب وما ينبغي تغييره. وتعرض شاشة النشاط نسبة النجاح والزمن الوسيط. |
| 🌙 **ساعات الهدوء** | التذكيرات الليلية تنتظر الصباح. أما الإرسال اليدوي فلا يتأجّل أبدًا — فأنت أمام الشاشة. |
| ⬆️ **تحديث من داخل التطبيق** | يستعلم من GitHub Releases، وينزّل المثبّت، ويتحقق منه مقابل بصمة SHA-256 المنشورة، ثم يسلّمه للنظام. وعلى أندرويد يفتح ملف APK ليتولّاه مثبّت النظام. يمكن إيقافه؛ ولا يُرسل شيئًا سوى الطلب نفسه. |
| 🌍 **ست لغات** | English و简体中文 وFrançais وEspañol وРусский والعربية — بتخطيط كامل من اليمين إلى اليسار للعربية. |
| 🎨 **مريح للعين** | وضع فاتح وداكن، تبعًا للنظام أو مثبّتًا، ستة ألوان تمييز، وكثافتان للعرض، مع اختيار الخط حسب نظام الكتابة: Songti (宋体) للصينية وTimes New Roman للنص اللاتيني وعلامات الترقيم. |

## التنزيل

أحدث إصدار من **[صفحة الإصدارات](https://github.com/Aevorine/Aevistle/releases/latest)**.

| المنصة | الملف | ملاحظات |
|---|---|---|
| Windows 10/11 (x64) | `Aevistle-<version>-win-x64-setup.exe` | مُثبِّت، ينشئ اختصارًا في قائمة ابدأ وعلى سطح المكتب |
| Windows 10/11 (x64) | `Aevistle-<version>-win-x64-portable.exe` | ملف واحد بلا تثبيت، يعمل من ذاكرة USB |
| أندرويد 7.0+ | `Aevistle-<version>.apk` | للهواتف والأجهزة اللوحية. فعّل أولًا «تثبيت التطبيقات غير المعروفة» لمتصفحك أو مدير الملفات. |

`<version>` هو الرقم المكتوب في صفحة
[أحدث إصدار](https://github.com/Aevorine/Aevistle/releases/latest)، وهو نفسه ما
تقرأه الشارة في أعلى الصفحة. لم يُكتب هنا صراحةً عن قصد، حتى لا يَقدُم هذا
الجدول مع الوقت.

> سينبّه SmartScreen في ويندوز إلى ناشر غير معروف؛ هكذا تبدو أي نسخة بلا شهادة
> توقيع مدفوعة. اختر **مزيد من المعلومات ← تشغيل على أي حال**، أو تحقّق أولًا من
> بصمة SHA-256 المنشورة في صفحة الإصدار.

## البداية في أربع خطوات

1. **أضف بريدك.** الإعدادات ← إضافة حساب. اختر المزوّد فيملأ Aevistle الخادم
   والمنفذ ونوع التشفير بدلًا عنك.
2. **احصل على كلمة مرور للتطبيقات.** ترفض Gmail وOutlook وYahoo وiCloud وQQ
   و163 كلمة مرورك المعتادة من أي تطبيق خارجي. ونافذة الحساب تحيلك مباشرة إلى
   صفحة إنشائها.
3. **اختبر الاتصال.** زر واحد يستوثق دون إرسال شيء، فتكتشف المشكلة الآن لا في
   الثالثة فجرًا.
4. **اكتب التذكير**، أرفق ما تحتاجه، ثم اختر **جدولة**.

## الخصوصية

لا يملك Aevistle أي خادم. لا حساب تُنشئه، ولا قياسات استخدام، ولا تقارير أعطال.

قائمة قصيرة وثابتة بما يغادر جهازك، ولا شيء غيرها:

1. **اتصال SMTP بمزوّد بريدك أنت** — رسالتك، إلى الصندوق الذي أعددته.
2. **اتصال IMAP بمزوّد بريدك أنت** — فقط للحسابات التي فعّلت فيها الاستقبال،
   وفقط لجلب بريد ذلك الحساب.
3. **صورة بعيدة داخل رسالة مستلمة، فقط حين تطلب تحميلها صراحةً** — كل صورة
   محجوبة افتراضيًا ومستبدلة بعنصر نائب، لأن وسم `<img>` البعيد أقدم حيلة
   تتبّع في البريد الإلكتروني. وعملية الجلب نفسها محمية من إعادة التوجيه إلى
   شبكتك الداخلية (لا عناوين IP داخلية، ولا اتّباع لأي إعادة توجيه).
4. **التحقق من التحديثات**، إن تركته مفعّلاً: طلب `GET` غير موثَّق إلى
   `api.github.com` يسأل عن أحدث إصدار. لا يحمل أي بيانات حساب، ولا محتوى
   رسائل، ولا بيانات استخدام. أوقفه من **الإعدادات ← التحديثات** فلا يُرسل
   التطبيق حينها أي طلب من عنده.

كل شيء يبقى على جهازك:

| | Windows | أندرويد |
|---|---|---|
| الإعدادات والجدولات وجهات الاتصال والسجل | `<مجلد البيانات>\state.json` | تخزين التطبيق |
| كلمات مرور البريد | `secrets.json` مشفّرًا بـ DPAPI | Android Keystore (مدعوم بالعتاد حيثما توفّر) |
| كلمات مرور IMAP | نفس الملف، نفس التشفير، مُدخل مستقل في Keystore عن كلمة مرور SMTP لذلك الحساب | نفس الـ Keystore، مُدخل مستقل |
| نسخ المرفقات | `<مجلد البيانات>\attachments\` | `<مجلد البيانات>/attachments` |
| ذاكرة تخزين البريد الوارد المؤقتة (النصوص، المرفقات) | `<مجلد البيانات>\inbox\` — ذاكرة مؤقتة محدودة بعمر وحجم أقصى يمكنك ضبطهما من **الإعدادات**، وحذفها آمن: تعيد المزامنة فحسب | `<مجلد البيانات>/inbox` |

يبدأ مجلد البيانات في `%APPDATA%\Aevistle` على ويندوز، وفي التخزين الخاص على
أندرويد، ويتيح لك **الإعدادات ← مجلد البيانات** نقله إلى أي مكان تستطيع
الكتابة فيه. وعلى أندرويد يكون الاختيار بين وحدات التخزين التي يسمح النظام
فعليًا للتطبيق بالكتابة فيها (الخاص، والمشترك، وبطاقة SD)، لأن مجلدًا يُختار عبر
مُنتقي المستندات لا يستطيع مُرسِل الخلفية فتحه بعد ساعات.

وهناك أمران يبقيان مكانهما عن قصد: كلمات المرور، لأنها مشفّرة بحساب نظامك
وعديمة الفائدة في مكان آخر، وجدول المنبّهات على أندرويد، حتى لا يمنع نزعُ
البطاقة انطلاقَ تذكير.

وتصدير الإعدادات لا يتضمن كلمة مرور أبدًا.

## الأمان

نموذج التهديد وقرارات التحصين وطريقة الإبلاغ عن ثغرة، كلها في
**[SECURITY.md](../SECURITY.md)**.

باختصار: طبقة العرض تعمل دون أي صلاحية Node، مع عزل السياق وسياسة CSP صارمة؛
وأي نص متجه إلى ترويسة بريد يُرفض إن احتوى فاصل أسطر (هكذا تنشأ المُرحِّلات
المفتوحة)؛ وشهادات TLS يجري التحقق منها ما لم تعطّل ذلك صراحةً لحساب بعينه؛ ويُعقَّم HTML
الرسالة المستلمة في العملية الرئيسية وفق قائمة سماح صارمة قبل أن يصل إلى طبقة
العرض أصلًا، ويُعرَض داخل إطار iframe معزول لا يُسمح فيه بتنفيذ أي سكربت مهما
كانت الحال؛ ومستقبِل المنبّهات على أندرويد غير مُصدَّر، فلا يستطيع تطبيق آخر أن
يجعل Aevistle يرسل بريدًا.

ويمكنك التحقق من ذلك كله بنفسك:

```bash
npm run audit:self
```

عشرون فحصًا، بمخرجات بلغة واضحة، ورمز خروج 1 إن وُجد ما يستدعي الانتباه.

## البناء من المصدر

**المتطلبات** — Node.js 20 فأحدث، ولأندرويد: JDK 17 فأحدث وAndroid SDK
(المنصة 36، وbuild-tools 35 فأحدث). ويعثر `npm run build:android` على JDK
وSDK مثبّتين ولو لم يكونا في `PATH`، فضبط `JAVA_HOME` اختياري.

```bash
git clone https://github.com/Aevorine/Aevistle.git
cd Aevistle
npm install
```

| المهمة | الأمر |
|---|---|
| التشغيل في المتصفح (بلا SMTP، وكل ما عداه حقيقي) | `npm run dev` |
| فحص الأنواع | `npm run typecheck` |
| تدقيق الأمان | `npm run audit:self` |
| تشغيل تطبيق سطح المكتب | `npm start` |
| بناء مثبّتات ويندوز | `npm run dist:win` |
| بناء حزمة أندرويد | `npm run build:android` |

يقرأ توقيع إصدار أندرويد من `~/.aevistle/keystore.properties` أو من متغيرات
`AEVISTLE_KEYSTORE*`. وفي غياب كليهما يرجع البناء إلى مفتاح التصحيح، فتبقى
الحزمة قابلة للتثبيت.

## كيف بُني

واجهة واحدة بـ React وTypeScript، وغلافان أصليان.

```
src/core/        مستقل عن المنصة: نموذج المجال، محرك التكرار، التحقق،
                 إعدادات مزوّدي SMTP — بلا DOM ولا Node ولا أندرويد
src/             واجهة React (ست لغات، وضعان للسمة)
    ↓ PlatformBridge — الوصلة الوحيدة بين الواجهة ونظام التشغيل
electron/        ويندوز: nodemailer + imapflow، تخزين الأسرار بـ DPAPI، شريط
                 النظام، تعقيم HTML للبريد المستلم
android/         أندرويد: JavaMail (إرسال واستقبال)، Keystore، AlarmManager وWorkManager
```

محرك التكرار مكتوب بـ TypeScript وحدها عن قصد. فهو يحسب مسبقًا قائمة طوابع
زمنية مطلقة، ولا يفعل مجدوِل كل منصة سوى الإجابة عن «أيقظني عند اللحظة T» —
وبذلك تُكتب كل قواعد التقويم (السنوات الكبيسة، والشهور القصيرة، والتوقيت
الصيفي، وتخطي العطلة) مرة واحدة، بلغة واحدة، ويمكن اختبارها دون محاكٍ.

تفاصيل أوفى في **[ARCHITECTURE.md](ARCHITECTURE.md)**.
