## 电脑（Windows）

### 装好之后先做三件事

1. **加一个邮箱。** 设置 → 账户 → 添加账户。
   常见服务商（Gmail、Outlook、QQ、163、Yahoo、Zoho）选好之后服务器地址会自动填。
   Gmail 和 Outlook 可以直接「用 OAuth 2.0 登录」，不用去申请授权码。
2. **点「测试连接」和「测试收信」。** 两个按钮分别测发件和收件，会各自给出自己的结果。
   显示绿色才算通。不通的话它会直接说是哪一层失败（网络 / 端口 / 账号密码 / 证书）。
3. **打开设置 → 系统 → 「退出之后也继续收信」。** 见 [下面这一节](#关掉窗口之后还想收信)。

### 快捷键

**全局**（应用没在前台、甚至窗口已经收进托盘时也管用）

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Alt + A` | 把窗口叫到眼前；**再按一次收回去** |

这一个可以改。设置 → 系统 → 「用快捷键显示或隐藏窗口」，直接把想要的组合敲进去，
比如 `Ctrl+Shift+M`。旁边那行字会立刻告诉你成没成 —— 如果这个组合已经被别的程序占了，
它会说"已经被别的程序占用了"，而不是假装设好了。「关闭」按钮可以彻底不要这个快捷键。

**窗口内**

| 按键 | 作用 |
| --- | --- |
| `Ctrl + 1` … `Ctrl + 9` | 按顺序切到导航栏第 1 到第 9 个页面 |
| `Ctrl + K` | 打开命令面板（搜任何功能、任何联系人、任何模板） |
| `Ctrl + Z` | 撤销刚才那一步 |
| `?` | 打开快捷键一览（就是这张表的应用内实时版） |

**写邮件时**

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Enter` | 立刻发送 |
| `Ctrl + Shift + Enter` | 定时发送 |
| `Ctrl + Shift + P` | 发送前预检（收件人、附件、正文一起过一遍） |
| `Ctrl + Shift + H` | 打开发送历史 |
| `F9` | 进入专注模式，只剩正文 |

**看邮件时**

| 按键 | 作用 |
| --- | --- |
| `Esc` | 第一下退出正文内的查找，第二下关闭邮件 |
| 左右滑动（触摸屏） | 关闭当前邮件 |

> `Ctrl+1`…`Ctrl+9` 跟着导航栏的实际顺序走，不是写死的。
> 你把导航栏顺序调了，快捷键跟着变，应用内的快捷键表也跟着变。

### 托盘图标

右下角通知区域那个图标。

- **左键单击一下**：窗口出来。**再单击一下**：窗口收回去，任务栏里也不留。
  （如果你把设置里的「关闭窗口时缩小到托盘」关了，那它会最小化到任务栏而不是消失。）
- **右键单击**：菜单，从上到下是
  - 最上面一行是**下一个定时任务什么时候发** —— 这是显示，不是按钮，点不动。
  - 打开主窗口
  - 写邮件
  - 定时任务
  - 发送记录
  - 全部暂停 / 全部恢复（按当前状态显示其中一个）
  - 退出

**鼠标停在任何一个图标按钮上都会显示它叫什么** —— 导航栏、工具栏、邮件行里那些没有文字的圆形按钮都一样。

### 关掉窗口之后还想收信

分两种"关掉"，行为不一样：

| 你做的事 | 结果 |
| --- | --- |
| 点窗口右上角的 ✕ | 默认收进托盘，**进程还在，照常收信照常提醒** |
| 托盘右键 →「退出」 | 进程真没了。**这时候必须靠下面这个开关** |

**设置 → 系统 →「退出之后也继续收信」**（默认关）。

打开之后，Windows 里会多一条计划任务，每 15 分钟用你自己的账户身份悄悄启动一次应用，
查一遍新邮件；应用已经在跑的时候它什么也不做。设置里那行字直接写着删除它的命令，
随时可以撤销，也可以直接把开关关掉。

**这一行下面会说实话**：

- 显示正常提示 → 任务建好了，设置也对。
- 显示"Windows 拒绝创建后台任务" → 没建成，这个开关目前没起作用。
- 显示"用的是它自己的默认设置——笔记本一拔电源它就不会运行" → 任务在，但设置不对。
  **把开关关掉再打开**，会用正确的设置重建一次。

> 0.3.26 之前建的任务全部属于第三种。装上 0.3.26 之后第一次启动会自动修好，不用你动手。

顺带一提：**设置 → 系统 →「开机时启动」** 是另一回事 —— 它管的是开机自动启动，
「退出之后也继续收信」管的是被你手动退出之后自动拉起来。两个都开最稳。

### 更新

设置 → 更新。它会去 GitHub 看有没有新版本，有的话给出下载按钮。

下载完成后会**先校验哈希、再验签名**，两样都对才允许安装。
签名用的是项目自己的密钥，公钥就打包在应用里 —— 换句话说，
一个被人中途替换过的安装包过不了这一关，它会告诉你，而不是装上去。

## 安卓手机 / 平板

### 安装

1. 从 [GitHub Releases](https://github.com/Aevorine/Aevistle/releases/latest) 下载 `Aevistle-x.y.z.apk`。
2. 点开，系统会问「是否允许从此来源安装应用」→ 允许。
3. 装完第一次打开，按提示加邮箱，步骤跟电脑一样。

> 想确认下载的包没被人动过：同一个 Release 里有 `SHA256SUMS.txt`（哈希）、
> `SHA256SUMS.txt.asc`（GPG 签名）和 `aevistle-public-key.asc`（公钥）。

### 权限：四项，缺一项就收不到

打开 **设置 → 通知**，往下拉到「安卓权限」，这里有四行。
**前三行全绿也不代表能收到**，第四行才是真的在看后台服务此刻还活着没有。

| 行 | 没给会怎样 | 怎么给 |
| --- | --- | --- |
| **通知** | 邮件收到了，但一声不吭 | 点旁边的按钮 → 系统弹框 → 允许 |
| **闹钟和提醒** | 定时发送会被系统推迟，可能晚几十分钟 | 点按钮 → 跳到系统页 → 打开「允许设置闹钟和提醒」 |
| **电池优化** | 后台收信会被系统掐掉 | 点按钮 → 系统弹框 → 选「允许」/「不优化」 |
| **后台收信服务** | **这不是权限，是状态。**显示"已被停止"就是真的停了 | 见下面 |

**第四行显示"已被停止"时**，旁边会出现「允许自启动」按钮。这一步系统没有 API，
只能跳到厂商自己的页面，按机型分别是：

- **华为 / 荣耀**：手机管家 → 应用启动管理 → 找到 Aevistle → 关掉「自动管理」，
  然后把「允许自启动」「允许关联启动」「允许后台活动」三个都打开。
- **小米 / 红米**：安全中心 → 应用管理 → 权限 → 自启动 → 打开 Aevistle。
  再去 设置 → 应用设置 → 应用管理 → Aevistle → 省电策略 → 无限制。
- **OPPO / 一加 / realme**：设置 → 电池 → 应用耗电管理 → Aevistle → 允许后台运行、允许自启动。
- **vivo / iQOO**：i管家 → 应用管理 → 权限管理 → 自启动 → 打开 Aevistle。
- **三星**：设置 → 电池 → 后台使用限制 → 把 Aevistle 从"休眠应用"里移出来。

跳不过去的机型会退回到应用详情页 —— 不会给你一个点了没反应的按钮。

### 日常操作

**收信**

- 应用开着的时候，下拉刷新，或者点右上角的刷新。
- 应用关着的时候，后台服务每 90 秒查一次；服务被系统掐掉之后退回到每 15 分钟一次。
- **从最近任务里把应用划掉**，5 秒后服务会自己起回来（0.3.26 起）。
  如果你的手机连这个也拦，那就靠 15 分钟那一档，邮件还是收得到，只是慢一点。

**新邮件通知**

- 通知栏那条消息**直接点**：打开这封信。
- 通知上有一个**「标为已读」**按钮：不用打开应用就能标记，标记结果会同步回服务器。

**验证码**

- 验证码页面（导航栏里的「验证码」）会把最近收到的验证码单独拎出来放大显示。
- 默认**自动复制到剪贴板**，收到就能直接粘。
- 通知里也会直接带上验证码本身，不用点进来。

**写邮件 / 定时发送**

- 底部导航「撰写」→ 写完之后，
  - 直接发：点「发送」。
  - 定时发：点「定时」，选日期时间。到点了应用即使没打开也会发。
- 定时任务发出去之后，成功或失败都会有通知（可以在设置里分别关掉）。

**手势**

| 手势 | 作用 |
| --- | --- |
| 在邮件列表某一行上左右滑 | 划出「已读 / 删除」等操作 |
| 打开的邮件上左右滑 | 关闭这封邮件 |
| 列表顶部下拉 | 刷新 |
| 长按邮件行 | 出菜单（标为已读、复制发件人等） |

### 更新

设置 → 更新 → 检查。有新版会下载 APK 并调起系统安装器。
安装前同样先校验哈希和签名，不通过就不装。

> 需要「安装未知应用」权限，系统会在需要时问你。这个权限**只能**让系统弹出安装确认框，
> 不能静默安装 —— 每一次安装都还是你自己点的。

## 两台设备之间同步

电脑和手机在**同一个 Wi-Fi** 下，可以直接把账户、模板、联系人、定时任务同步过去，
不经过任何服务器。

1. 电脑：设置 → **配对** → 「配对新设备」→「显示配对码」，屏幕上出现二维码。
2. 手机：设置 → **配对** → 「使用另一台设备的配对码」，用相机对准二维码。
   相机用不了就把那串码直接粘进去 —— 两条路都在同一个界面上。
3. 配对成功后两边都会列出对方。之后点「同步」即可。

想解除：在列表里选中对方 → 撤销。**它只清除本机这一侧** —— 这个应用没有服务器，
联系不到对方设备，所以对方那边不会有任何东西被删掉。下次它来同步时会被要求重新配对。

**密码是单独加密传的**，跟其余数据用不同的密钥；对方设备打不开密码的时候，
账户照样过去，只是需要在那边重新输一次密码 —— 而不是悄悄同步一个用不了的账户。

## 出问题时先看哪里

| 症状 | 先看这里 |
| --- | --- |
| **邮件收到了，但没提醒** | **记录 → 收件**。见下面一节 |
| 收不到新邮件通知（电脑） | 设置 → 系统 →「退出之后也继续收信」那行字说了什么 |
| 收不到新邮件通知（手机） | 设置 → 通知 → 安卓权限，**四行都看**，尤其第四行 |
| 某一个邮箱一直同步失败 | 设置 → 账户 → 那个账户下面会写着上次失败的原文 |
| 定时任务没按时发 | 手机：「闹钟和提醒」权限；电脑：应用是不是被真的退出了 |
| 图片显示不出来 | 邮件顶部那条提示会说是被拦了还是加载失败，以及为什么 |
| 想知道到底发生了什么 | 导航栏「发送记录」，每一条都有原始错误 |
| 不知道该看哪一项 | 设置 → **邮件自检** |

### 邮件收到了，但没有提醒

导航栏 **记录 → 收件**。每次同步只要有东西可说，就会写一行，直接说明原因：

| 你看到的 | 意思 | 怎么办 |
| --- | --- | --- |
| `提醒了 N 封` | 通知发出去了 | 没弹出来就是系统那边挡了：Windows 设置 → 通知里找 Aevistle；手机去应用通知权限 |
| `N 封别的设备已经读过，按规则没有提醒` | **最常见的一条。**手机上还有别的邮件应用在收同一个信箱，邮件几秒内就被标成已读了 | 设置 → 通知 → 打开**「别的设备读过的也提醒我」** |
| `N 封太旧，不算刚到` | 邮件本身的时间太早，不当作刚到的 | 正常行为。整个信箱补同步时会出现 |
| `第一次同步，N 封只用来建立基线` | 这个账户这次启动后的第一次同步 | 正常行为，就是为了不让开应用时一口气弹十几条 |
| `「收到新邮件时通知我」是关着的` | 开关关了 | 设置 → 通知，打开它 |
| `正处在免打扰时段` | 在你设的安静时段里 | 设置 → 通知 → 免打扰时段 |

**这一页什么都没有**，说明这段时间根本没有新邮件到达——问题在收信不在提醒，
去看上面表格的其他行。

这里**只记数字**，不会记发件人、主题和内容，导出成 CSV 也一样。

**邮件自检**（设置里那一项）会按顺序检查：运行平台、原生桥接、通知权限、精确闹钟、
有没有账号、账号必填项、保存的凭据、发信（SMTP）、收信（IMAP），每一项给出
`正常 / 警告 / 失败 / 不适用`，失败的那一条下面直接写服务器的原话。

它会**真的连一次你的服务器**，但**不会给任何人投递邮件**。

还是不行的话，把自检结果和「发送记录」里的报错原文一起贴到
[Issues](https://github.com/Aevorine/Aevistle/issues)。
