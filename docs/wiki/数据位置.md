## 先查看实际目录

Windows 中，在应用设置里查看数据目录，并使用应用提供的数据目录管理功能。默认位置来自 Electron 的 userData，但可以修改；不要把安装目录或便携 EXE 所在目录当作数据目录。

| 项目 | 内容 |
|---|---|
| `state.json` | 账户配置、提醒、联系人、模板、活动记录和设置 |
| `secrets.json` | 受系统账户保护的加密凭据 |
| attachments、pasted 文件夹 | 邮件附件和粘贴的图片 |
| `dispatch-ledger.json` | 每次发送的执行记录 |
| `control-audit.json` | 本地控制请求的审计记录 |

需要改变位置时，使用应用内迁移功能。手动复制正在使用的文件前，先协调或关闭应用，并保留必要备份。

## 备份不等于迁移密码

普通导出不包含密码，但仍可能包含真实邮箱、计划和正文。导入后可能需要重新输入授权码；把 Windows 的加密凭据文件复制到另一个系统账户或电脑，并不等于完成有效的凭据迁移。

Android 使用应用私有存储和系统密钥库。用应用的导入、导出功能迁移资料，不要猜测并公开其内部目录。浏览器演示有独立的本地状态，不是原生发信应用。

## 本地控制文件

桌面集成读取 ~/.aevistle/endpoint.json 中的当前端口和令牌。它是敏感的控制接口配置，不是可以公开分享的计划备份。投递目录的请求和结果也可能包含邮件指令，详见[本地控制接口](本地控制接口.md)。

提交日志或备份前，按[安全模型](安全模型.md)删除或遮盖敏感内容。
