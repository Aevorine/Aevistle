## 建立一条提醒

选择发送账户，填写收件人、主题和正文，按需添加附件，再检查发送时间。周报提醒、每月事项或重复发送的计划，应设置循环规则，并核对下一次实际执行时间。

| 设置 | 需要检查什么 |
|---|---|
| 单次或循环 | 下一次执行是否符合预期 |
| 收件人、抄送、密送 | 地址是否正确，是否包含不应收到邮件的人 |
| 附件 | 是否选对文件，是否超过服务商限制 |
| 工作日策略 | 是否要遵循中国调休或单位工作日历 |
| 免打扰与接收时间窗口 | 是否会将发送延后 |
| 补发策略 | 电脑休眠或错过执行后怎样处理 |

## 修改、暂停和恢复

在提醒中使用编辑、暂停、恢复或删除功能。修改循环提醒后，重新核对下一次执行时间；循环规则的修改可能影响后续多次发送，不一定只改变某一天。

## 收信与活动记录

需要在应用里收信时，再启用 IMAP 并检查接收设置。打开应用才收到邮件时，优先排查手机后台和联网权限，见[常见问题](常见问题.md)。

查看活动日志中的实际发送结果。排队成功、连接测试通过、服务商接受邮件和对方收到邮件是不同阶段；向客户或同事重发前，先确认上一次任务状态，避免重复发送。

## 国内工作安排

不要把“周一至周五”直接等同于调休工作日。国内工作邮件应检查[工作日历](工作日历.md)，公司轮班或学校安排则按实际日期调整。涉及工作附件时，发送前确认权限与收件人，见[安全模型](安全模型.md)。
