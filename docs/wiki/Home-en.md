Aevistle schedules email on Windows and Android using your own SMTP/IMAP provider. Reminders and their rules are kept on your device; actual mail is handed to the provider you configure. The device must be powered on, connected and allowed to run when delivery is due.

Published application builds are Windows x64 and Android APK. [中文导航](中文导航.md)

## Downloads

Take the application files and verification material from the [latest release](https://github.com/Aevorine/Aevistle/releases/latest).

| File | For |
|---|---|
| `Aevistle-VERSION-win-x64-setup.exe` | Windows installer |
| `Aevistle-VERSION-win-x64-portable.exe` | Windows portable executable |
| `Aevistle-VERSION.apk` | Android application |
| `SHA256SUMS.txt and its signatures` | Download integrity and release verification |

VERSION stands for the release version. Installation and data storage are separate; see [Data location](Data-location.md).
