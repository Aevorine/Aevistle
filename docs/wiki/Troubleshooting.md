# Troubleshooting

1. Check the activity log for the provider's reported error.
2. Confirm the account, server, port and TLS mode match the provider's settings.
3. Confirm the device is powered on, connected and permitted to run in the background.
4. Check quiet hours, working calendars and recipient delivery windows before assuming a reminder is missing.
5. For updates, download the latest release directly if automatic download fails. Preserve your application data.

When reporting a problem, include the app version, OS version, steps and expected/actual result. Remove credentials, recipients, private messages and machine-specific paths.
