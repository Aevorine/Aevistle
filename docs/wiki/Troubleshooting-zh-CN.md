# 故障排查

简体中文 | [English](Troubleshooting.md)

1. 查看活动日志，确认邮件服务商返回的具体错误。
2. 核对账户、服务器地址、端口和加密连接方式（TLS），确保与服务商的要求一致。
3. 确认设备已开机、已联网，并允许应用在后台运行。
4. 检查免打扰时段、工作日历和收件人的发送时间窗口，再判断提醒是否漏发。
5. 如果自动更新下载失败，请直接从[最新版本页面](https://github.com/Aevorine/Aevistle/releases/latest)下载安装包，并保留现有应用数据。

反馈问题时，请提供应用版本、操作系统版本、复现步骤，以及预期结果和实际结果。发送前，移除凭据、收件人地址、私人邮件内容和能识别个人电脑的本地路径。
