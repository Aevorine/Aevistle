# 国内常见问题排查

简体中文 | [English](Troubleshooting.md) · [返回中文首页](Home-zh-CN.md)

## QQ / 163 / 126 提示密码错误或登录失败

按这个顺序检查：

1. 账户中是否填写了邮箱服务商生成的客户端授权码，而不是网页版登录密码。
2. 邮箱官方设置中是否已开启 SMTP；需要收信时，是否同时开启 IMAP。
3. 完整邮箱地址、服务器域名、端口和加密方式是否匹配。[配置表](Installation-zh-CN.md)列出的是个人邮箱预设，企业邮箱需使用管理员提供的配置。
4. 授权码是否被撤销或重新生成过；旧码失效后，要更新应用里的凭据。
5. 查看活动日志中的具体服务商错误。网页能登录，不代表客户端服务和授权码已配置正确。

网易授权码入口见[官方帮助](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac286624f309a1a7089)。QQ 邮箱请从[官方帮助中心](https://service.mail.qq.com/)查看当前服务开通入口。

## 连接测试通过，但对方没有收到邮件

连接测试不会发送邮件。先建立一条发给自己、几分钟后执行的测试提醒，然后核对活动日志中的实际发送结果。若发送被拒绝，按日志检查服务商限额、附件大小或账户权限；若服务商已接受邮件，再检查收件方的垃圾邮件、退信和过滤规则。

不要因多次重试而连续向真实客户或同事发送重复邮件。先确认前一次任务的状态，再决定是否重发。

## 调休周末不发送，或假期仍发送

先核对中国工作日历的年份、假期和补班日，再检查这条提醒是否启用了工作日策略。每条提醒默认不使用工作日历；日历配置完成后，不会自动改变所有提醒。

“每周一至周五”和“按中国调休工作日”是两种不同规则。单位或学校另有安排时，在工作日历中按实际情况调整；法定日期可对照 [2026 年国务院通知的官方转载](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。同时检查免打扰时段和收件人的接收时间窗口，避免把规则延后误认为漏发。

## Windows 关掉窗口后没发送

确认应用仍在系统托盘运行，没有选择退出。继续检查电脑是否休眠、关机或断网。恢复运行后的补发或跳过行为，还取决于提醒的补发策略；请查看活动日志，不要假定所有错过的任务都会立即重发。

如果是单位电脑上的网络限制，请让管理员确认邮件服务器的访问要求。不要关闭 TLS 证书校验来尝试绕过问题。

## 手机锁屏后延迟，打开应用才恢复

先区分“没有发送”与“没有通知”：在活动日志中查看发送或收信记录，再检查通知权限。

对支持 Android APK 的手机，检查 Aevistle 的精确闹钟、后台活动、联网和电池优化权限。华为适用机型可按[官方说明](https://consumer.huawei.com/cn/support/content/zh-cn15872069/)搜索应用启动管理，检查自启动和后台活动设置；该说明还区分不同系统版本的入口，不要把其中一个路径套用到所有手机。

在荣耀、小米 / Redmi、OPPO / realme、vivo 等设备上，可在系统设置中搜索“自启动”“后台运行”“电池优化”等关键词。菜单随品牌和版本变化，以设备实际选项为准；允许通知不等于允许后台执行。应用内的厂商设置入口若没有打开目标页面，可以直接从系统的应用详情进入查找。

修改后，建立一条发给自己的短时间提醒，锁屏并观察结果。强行停止应用、关机或系统继续限制后台时，不能据此保证准点发送。

## GitHub 页面打开慢或下载失败

分别检查页面能否打开，以及 Releases 附件能否下载：两者可能有不同的网络表现。确认网络连接正常后重试官方发布页，或使用你能正常访问 GitHub 的网络；自动更新失败时，可以手动下载同一发布页上的安装包。不要把下载错误当成邮箱配置错误。

请保留现有应用数据，不要通过清空账户或卸载应用来解决附件下载问题。安装前核对发布文件的校验值和签名，步骤见[隐私与安全](Privacy-and-Security-zh-CN.md)。

## 提交中文问题反馈

请说明以下信息：应用版本；Windows / Android 版本与手机品牌；邮箱类型（QQ、163、126 或单位邮箱，无需填写真实地址）；预期发送时间与所用时区；复现步骤；活动日志中的错误和已经尝试的处理办法。

截图和日志请先按[隐私说明](Privacy-and-Security-zh-CN.md)遮盖敏感内容，然后通过 [Issues](https://github.com/Aevorine/Aevistle/issues/new/choose)提交。
