## 开发环境

| 部分 | 当前源码要求 |
|---|---|
| JavaScript | Node.js 22.12.0 或更新版本、npm |
| Windows 打包 | Windows x64 构建环境 |
| Android | JDK 21、Android SDK platform 36 |
| Android 安装包 | minSdkVersion 24 |
| 对外发布 | 仓库外签名密钥与有权发布的 GitHub 凭据 |

跟随更新的源码时，以 package.json 和 Android 构建配置中的要求为准。

## 从源码运行

克隆仓库后安装锁定的依赖：

~~~powershell
git clone https://github.com/Aevorine/Aevistle.git
cd Aevistle
npm ci
~~~

以上步骤建立本地开发目录。再按需要选择命令：

| 任务 | 命令 |
|---|---|
| 浏览器演示，不含原生 SMTP 发信 | `npm run dev` |
| 原生桌面应用 | `npm start` |
| 类型检查 | `npm run typecheck` |
| 现有完整 CI 检查 | `npm run check` |
| Windows 安装版与便携版 | `npm run dist:win` |
| Android 发布 APK | `npm run build:android` |

需要主动运行依赖浏览器的检查时，先安装 tests 目录的独立依赖：npm ci --prefix tests，并准备兼容的浏览器。

## 产物与签名

Windows 打包产物位于 release。Android 发布包位于 android/app/build/outputs/apk/release/app-release.apk。签名材料保存在仓库之外，由维护者的外部配置或环境变量提供。

Android 发布构建缺少有效签名配置时会失败，不会静默换成调试签名。不要把私钥、密码或密钥库文件提交到 Git 或 Actions 机密配置。

发布脚本要求版本、源码和安装包一致，会签署清单、上传、下载公开副本并验证校验值与签名。发布需要实际权限与签名材料，详见 [scripts/release.mjs](https://github.com/Aevorine/Aevistle/blob/main/scripts/release.mjs) 和 [SECURITY.md](https://github.com/Aevorine/Aevistle/blob/main/SECURITY.md)。
