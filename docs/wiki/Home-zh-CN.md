# Aevistle 使用指南

简体中文 | [English](Home.md)

Aevistle 支持在 Windows 和 Android 上定时发送邮件，使用你自己的邮件服务商发送邮件（SMTP），并可选择接收邮件（IMAP）。到达发送时间时，设备需要保持开机并连接网络。
