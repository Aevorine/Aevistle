# Aevistle 中国大陆用户指南

简体中文 | [English](Home-en.md)

Aevistle 可以用你的 QQ 邮箱、网易 163/126 邮箱，或单位提供的邮箱，在 Windows 和支持 Android APK 的手机上定时发送邮件。这份指南按国内常见的邮箱、北京时间和调休安排组织，帮助你完成从安装到第一次定时发送的配置。

## 从这里开始

1. [安装与国内邮箱配置](Installation-zh-CN.md)：下载安装包，获取邮箱授权码，填写服务器参数并测试连接。
2. [隐私与安全](Privacy-and-Security-zh-CN.md)：保护邮箱授权码、工作邮件和备份文件，了解哪些信息可以公开反馈。
3. [国内常见问题排查](Troubleshooting-zh-CN.md)：处理授权失败、调休日期不对、锁屏后延迟和 GitHub 下载失败等问题。

## 适合怎样使用

- 给自己定时发送学习计划、缴费提醒或每月事项清单。
- 给同事发送周报提醒，按照单位实际的工作日历安排发送。
- 在春节、国庆等假期暂停工作邮件，同时保留周末调休上班日的发送安排。
- 给海外联系人发邮件时，单独设置对方的时区和接收时间窗口。

Aevistle 的调度在你的设备上执行。到达发送时间时，设备需要开机、联网，并允许应用运行。电脑休眠、手机强行停止应用或系统限制后台活动，都可能影响发送时间；邮件服务商接受邮件后，对方何时收到仍取决于邮件投递过程。

## 第一次配置建议

先使用自己的邮箱建立一条几分钟后的测试提醒，确认能够收到邮件；再配置循环规则、附件和工作日历。国内工作邮件请同时检查北京时间、法定节假日和单位自己的调休安排。
