Aevistle 使用你的 QQ 邮箱、网易 163/126 邮箱或单位邮箱，在 Windows 和支持 Android APK 的手机上定时发送邮件。调度在设备上执行，邮件仍通过你配置的服务商投递；到达发送时间时，设备需要开机、联网并允许应用运行。

这套中文指南按中国大陆的邮箱配置、北京时间、调休安排和手机后台限制组织。[English](Home-en.md)

## 下载

从[最新版本](https://github.com/Aevorine/Aevistle/releases/latest)下载应用和对应的校验文件。

| 文件 | 给谁 |
|---|---|
| `Aevistle-版本号-win-x64-setup.exe` | Windows 安装版 |
| `Aevistle-版本号-win-x64-portable.exe` | Windows 便携版 |
| `Aevistle-版本号.apk` | 支持 Android APK 的手机 |
| `SHA256SUMS.txt 及签名文件` | 核对下载文件与发布签名 |

## 第一次使用

先按[首次设置](首次设置.md)添加邮箱，并给自己安排一条几分钟后的测试提醒；确认实际收到邮件，再配置循环规则、附件和[工作日历](工作日历.md)。
