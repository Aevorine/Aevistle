## 开启本机控制

在桌面应用设置中启用本地控制接口。它默认关闭，只监听 127.0.0.1，并在应用启动时重新生成令牌。立即发信另有独立权限，开启控制接口本身不代表允许立即发送。

## CLI 与 MCP

客户端位于 integrations，也以 @aevorine/aevistle-control 发布到 GitHub Packages。使用源码目录时，先运行只读命令：

~~~powershell
node integrations/cli.mjs status
node integrations/cli.mjs list-reminders
~~~

命令会读取应用的当前接口配置。设置卡片可以复制包含当前本机路径的 MCP 配置命令；无依赖服务端入口为 integrations/mcp-server.mjs。

| 能力 | 例子 |
|---|---|
| 读取 | 状态、提醒、近期活动、联系人与模板 |
| 安排任务 | 创建、暂停或取消提醒 |
| 立即发送 | 需要单独开启发送权限 |
| 查看收件箱 | 只提供邮件头，不提供正文或附件 |

## 应用未运行时

会修改数据的 CLI 请求可进入投递目录，等下次启动执行。排队成功不代表已经执行；应用运行后，需要查看请求结果和活动记录。

不要公开 endpoint.json、访问令牌、投递文件或结果。HTTP 接口拒绝浏览器式请求，也不是可以开放到远程网络的服务。完整操作、参数和排队语义见 [integrations/README.md](https://github.com/Aevorine/Aevistle/blob/main/integrations/README.md)。
