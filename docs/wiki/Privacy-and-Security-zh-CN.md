# 隐私与安全

简体中文 | [English](Privacy-and-Security.md)

账户凭据和邮箱数据保存在你的设备上。项目签名私钥保存在仓库之外，不会作为发布附件上传，也不会写入 GitHub Actions 的机密配置。

提交问题时，请勿附带账户密码、OAuth 授权令牌、真实收件人地址、完整邮箱导出文件、本地控制接口配置文件，或包含私人邮件的截图。示例地址请使用 example.com；分享服务商日志前，请先遮盖敏感内容。

安全政策、网络访问边界、发布文件验证步骤和漏洞报告方式见 [SECURITY.md](https://github.com/Aevorine/Aevistle/blob/main/SECURITY.md)。本地控制接口默认关闭；启用后仅通过本机回环地址访问，并使用会话令牌进行鉴权。通过控制接口立即发送邮件，还需要单独开启发送权限。
