## 在局域网中配对

1. 让电脑和手机处于能够互相访问的网络。
2. 在一台设备打开配对页面并显示二维码。
3. 用另一台设备在一次性二维码有效期内扫描。
4. 核对接收设备和同步范围后再确认。

同一个 Wi-Fi 不一定能够互通：访客网络隔离或防火墙可能阻止设备间连接。Aevistle 没有云端中转或中转点服务端；不互通时，可以使用离线配对文件。

## 选择同步范围

| 范围 | 包含什么 |
|---|---|
| 账户 | 所选账户配置 |
| 计划 | 提醒和工作日历 |
| 联系人 | 所选联系人记录 |
| 模板 | 邮件模板 |
| 外观 | 界面偏好 |

实时加密配对在调用方明确提供凭据时，可以传输账户凭据。普通备份与离线配对文件则不包含凭据；不能把这两种路径混为一谈。

## 持续同步与离线文件

持续同步在应用打开时尝试设备上次的局域网地址。Android 上需要应用处于前台，不是关掉应用后仍运行的云同步。设备不再需要访问时，从已配对设备列表移除它。

离线配对文件用 PIN 派生的密钥加密，可以通过数据线或移动存储传递。文件仍包含所选的私人数据，应妥善保管。在多台设备启用同一计划前，确认由哪台设备执行发送，避免无意重复。
