## 更新来源

使用应用中按需开启的更新检查，或直接到[项目最新发布页](https://github.com/Aevorine/Aevistle/releases/latest)手动下载。Windows 安装版、便携版和 Android APK 是不同文件，按当前设备和所需安装方式选择。

## 核对文件与签名

| 校验 | 用途 |
|---|---|
| SHA-256 清单 | 检查文件是否变化或下载不完整 |
| GPG 分离签名 | 用公开密钥验证发布清单 |
| Ed25519 清单签名 | 桌面更新用内置公钥验证清单 |
| Android APK 签名 | 验证安装包签名与升级兼容性 |

Windows EXE 当前未配置 Authenticode 证书签名，与清单签名是两件事。完整步骤和公钥指纹见 [SECURITY.md](https://github.com/Aevorine/Aevistle/blob/main/SECURITY.md)。

## 保留已有数据

切换安装方式或迁移电脑前，导出必要备份并记录设置中显示的数据目录。不要通过清空账户来解决下载错误。Android 安装更新需要兼容的签名身份，其他密钥签出的包不能当作同一个应用的正常升级。

GitHub 下载失败时，先分别判断网页访问和附件下载是否正常，按[常见问题](常见问题.md)处理；手动下载后仍需校验。数据迁移见[数据位置](数据位置.md)。
