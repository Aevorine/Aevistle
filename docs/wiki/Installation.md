# Installation

English | [简体中文](Installation-zh-CN.md)

Download the current release from https://github.com/Aevorine/Aevistle/releases/latest.

Windows: choose the x64 setup installer or portable executable. Android: choose the APK and permit installation from the source you trust. Compare SHA-256 checksums with SHA256SUMS.txt; verify its GPG signature and the public-key fingerprint documented in [SECURITY.md](https://github.com/Aevorine/Aevistle/blob/main/SECURITY.md). Desktop updates verify the Ed25519 manifest signature.

Add an account using your provider's SMTP settings. Use an app password or the supported OAuth flow where required. IMAP receiving is optional. Closing the desktop window leaves scheduling in the tray; quitting the app or powering off the computer stops delivery. Android scheduling depends on its alarm and battery permissions.

See the [repository README](https://github.com/Aevorine/Aevistle/blob/main/README.md) for the complete setup guide and platform limitations.
