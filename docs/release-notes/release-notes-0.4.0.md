# Aevistle 0.4.0

一句话：**这一版给了你一颗后悔药、一把锁、一份杂志——外加一次独立安全审计的全部修复。**

0.3.x 的最后几个版本都在修"画不出来"。0.4.0 是功能版：五件新东西，每一件都是你
在增强菜单里亲手勾的。

---

## 一、撤销发送（默认开，5 秒）

按下"立即发送"后，邮件先在你机器上等 5 秒，屏幕上有一条横幅倒数，旁边一个按钮：
**撤销发送**。点它，草稿一字不差地回到表单里，什么都没发出去。

- 倒计时归零才真正连服务器。反悔窗口里邮件从未离开这台机器。
- 中途切到别的界面？**立即发出**而不是悄悄丢掉——按过发送的邮件绝不允许无声消失。
- 秒数在 设置 → 发送前确认 旁边选：关 / 5 / 10 / 30 秒。

## 二、应用锁（PIN）

设置 → 隐私 → 应用锁。设一个 4–12 位数字 PIN 之后：启动先解锁，按 **Ctrl+L**
随时上锁。锁屏是**整个界面被替换**，不是一层遮罩——锁着的时候界面树里没有任何邮件内容。

说清楚它是什么：这是**屏幕锁，不是磁盘加密**。能拿到你硬盘的人依然读得到邮件数据；
它防的是"别人坐到你解锁的电脑前"。忘记 PIN 只能重置应用数据——设置页开启前就写着这句话。

PIN 永远不落盘：存的是 6 万轮迭代哈希（实现逐字节对照 node:crypto 和 FIPS 标准
测试向量验证过，新门禁 `check:applock`，24 项断言）。

## 三、杂志阅读版式

阅读邮件时，工具栏多了一个打开的书本图标：一按，正文收窄成居中的阅读栏
（68 字符行宽——眼睛扫回行首不用找），像翻杂志；再按回到标准版式。选择记在
设置里，手机、平板、电脑同步同一个偏好。

## 四、书纸主题成为新安装的默认

7 套视觉主题里那套为宋体/Times 阅读而画的"书纸"（米白纸底、棕黑墨字、14:1 对比度、
1.75 行距）现在是**新安装**的默认。已经用过的设备保持你自己选的主题不变。

## 五、发送前小检查默认开启

正文写了"见附件"却什么都没附、日期措辞和实际发出时间对不上、收件人域名疑似打错、
大量收件人全在"收件人"栏暴露彼此地址——这四项检查一直都在，只是默认关着。
现在默认开（你手动关过的保持关）。全部只提醒、永不拦截。

## 键盘

- **Ctrl+L** 锁定应用（新）
- 收件箱列表页直接按 **j / ↓ / Enter** 打开最新一封（新）；阅读页里 j/k 上下封、
  u 标未读、Delete 删除、Ctrl+F 页内查找（原有）
- 按 **?** 随时弹出完整快捷键表

## 独立安全审计（2026-08-25，全部修复已在本版）

一位独立审查员对签名密钥、应用攻击面、仓库内容、GitHub 侧做了只读审计。
结论：**无高危，可安全发布**。本版顺手关掉了它找到的每一条：

- **P1**：更新器过去对"签名文件不存在"放行（上线过渡期的宽容）。现在**缺签名 =
  拒绝安装**，CI 门禁同步变硬——偷了发布凭证的人再也不能靠删一个文件把验证降级成
  "只查哈希"。
- P2：GPG 口令改走标准输入，不再出现在进程命令行里。
- P2：图片代理的 IPv6 黑名单补全 fe80::/10 全段，NAT64 内嵌地址按其内嵌的
  IPv4 同规则审查。
