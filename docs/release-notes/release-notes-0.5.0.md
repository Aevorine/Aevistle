# Aevistle 0.5.0

一句话：**你勾的二十项，这一版交付十七项半——外加两把修好的尺子和一道新防线。**

（另外三项属于"检查后发现早就做好了"：安卓通知分渠道、九屏懒加载、多账户并发收取，
详见文末"本来就有"一节。）

---

## 收件箱新能力（电脑 / 手机 / 平板同一份代码，一起生效）

### 正文全文搜索
搜索框的"正文"档现在搜**整封邮件的正文**（此前只搜预览那一行字）。
**怎么用**：收件箱右上角放大镜 → 选"正文"档 → 输入词。打开过或预取过的邮件都能命中；
从没打开过的邮件仍按预览文字匹配（它本地只有这一行字，如实处理）。

### 归档
不想删、又不想占收件箱的邮件，收起来。
**怎么用**：每行右侧的"收纳盒"图标一键归档；或 …菜单 → 编辑 → 勾选多封 → 归档。
找回：…菜单 → "已归档（N）" → 放回。归档只是本地收起——邮件还在服务器上，永不过期。

### 串成会话 / 按发件人分组
…菜单里两个开关："按主题串成会话"把 Re:/转发: 同一件事的往来收进一个栅栏；
"按发件人分组"把同一个人发的都归到一起。再点一次回到按日期。选择会记住。

### 已读到此为止
…菜单 → 编辑 → 勾中某一行 → "已读到此为止"：这行**以上（更新）的全部标已读**，
以下不动。清晨扫完邮件的一下。

### 一键回复（可带模板）
打开邮件 → 右上 … 菜单 → "回复"：撰写页已填好收件人（对方地址）、主题（自动加一个
Re:，不会叠成 Re: Re:）、发信账号（收到这封的那个账号）。存过模板的话，菜单里还有
"用模板回复：xxx"，正文直接带上模板内容。

### 导出邮件（电脑版）
打开邮件 → … 菜单 → "导出邮件（.eml）"（任何邮件客户端都能打开的标准格式）或
"导出为 PDF"。说明白：.eml 是按本地缓存**重建**的（正文+标题），不含附件和原始签名。

### Word / Excel 附件直接预览
点附件里的 .docx / .xlsx，直接在应用内看文字和表格内容（只显示内容，不显示排版），
不用再跳去别的程序。打不开的照旧交给系统。

### 发件人三张名单（设置 → 通知区）
- **静音发件人**：这些地址/域名来信永不响铃——连关键词都叫不醒它，双端（含安卓后台）生效。
  邮件照常收，只是不打扰。
- **自动关注 / 自动重要发件人**：这些人来的新邮件自动带上标记。手动设置的标记永远不被覆盖。
- 每条被静音的通知都记在"通知台账"里，不会无声消失。

### 验证码到达自动复制（设置 → 通知区，默认关）
打开后任何新到验证码直接进剪贴板。默认关，因为它会覆盖你剪贴板里原有的内容——开关旁边写着这句话。

### 记住你读到哪
收件箱、验证码、定时任务、联系人、模板、发送记录六个列表，切走再回来都停在原处，不再跳回顶部。

## 电脑版专属

- **托盘图标未读角标**：任务栏角标早就有，现在托盘小图标也带数字（超过 9 显示 9+），
  悬停显示"收件箱: N · 定时任务: M"。窗口关掉只留托盘时它照样更新。

## 修好的尺子与新防线

- `check:perf` 的"九个界面首次进入耗时"三个版本以来一直测不出（首启弹窗挡住了它的观察窗），
  修好后实测：最慢屏 348ms（预算 400ms），全部达标。
- CI 上界面一致性检查偶发误报（异步内容慢半拍被当成缺元素），现在等一等、再巡两遍才下结论。
- 新增 `check:soak` 压缩长跑：每圈走遍全部界面+开合读信+滚动，强制 GC 后采样，
  按斜率判泄漏。实测干净：每圈仅 +8.7 KB、DOM +4%。
- 新增 `check:body-search`、`check:office-preview` 两道内容闸，都先证明抓得住错才上岗
  （前者第一轮就抓到"表格里的 12 March 搜不到"的真 bug）。

## 本来就有（检查过、没重造）

- **安卓通知分渠道**：验证码走高优先级横幅渠道、普通邮件走安静渠道，四个渠道一直是分开的；
  系统设置里可对每个渠道单独设置声音。
- **九屏全部懒加载**：修好尺子后实测首访 2.2–348ms。
- **多账户并发收取**：三路并发+慢账户专用道，早有专属门禁。

## 耗电实测（需要你的手机）

`scripts/measure-android-battery.ps1`：手机连 USB 开调试后运行，它清零系统电量账本、
等你正常用几小时、然后把 Aevistle 名下的耗电摘出来给你看。几小时个位数 mAh 属正常。

## 怎么更新

电脑：应用内自动提示更新，或下载 `Aevistle-0.5.0-win-x64-setup.exe` 覆盖装。
安卓：下载 `Aevistle-0.5.0.apk` 覆盖装。数据都不受影响。
