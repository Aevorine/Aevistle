# Aevistle 0.4.1

一句话：**收件箱一滚动就"丢日期条、留空白带、盖住邮件行"的老毛病，这次连根拔了。**

---

## 修了什么

你报告的是：收件箱界面显示不全、不正确，而且很多版本之前就有。实测复现出来是这样：

- 邮箱一旦超过 60 封（真实邮箱都超过），列表会启用"只画看得见的那一段"的加速方式；
- 从这一版之前，加速方式摆放行的坐标是"画面坐标"，而日期条（"今天 / 昨天 / 星期几 / 具体日期"那条横杠）贴顶用的是"排版坐标"——两套坐标一滚动就对不上；
- 结果：**只要往下滚过第一屏**，每条日期条都离开自己的位置，原地留下一条空白带，跑掉的日期条堆在别处、直接盖在邮件行上面。显示不全 + 不正确，全对上了。

为什么拖了这么多个版本：以前所有收件箱测试只造 5 封假信——不到 60 封，加速方式根本不启动，所以每道门禁都是绿的。

## 这一版之后

- 行的摆放改用真实排版坐标，日期条回到每一天的开头，空白带和"盖住邮件"都消失；
- 日期条在滚动时会一直贴在顶上告诉你"现在看的是哪一天"，滚到一天的中段也不再消失；
- 顺手修掉一个"不正确"：老日期的分隔条以前印着"2026年7月30日 09:47"——那个时刻只是当天第一封信的时间，对"这一天"毫无意义，现在只印日期。

## 怎么保证不再犯

新增门禁 `check:inbox-scale`：造 6 个账户、140 封信、横跨 45 天的真实规模邮箱，
在电脑 / 平板 / 手机三种宽度、顶部 / 中段 / 底部 / 快速甩动四种滚动状态下，
逐像素检查"日期条都在自己位置上、没有空白带、没有盖住邮件行、日期条不带时刻"。
修复前它红（17 项），修复后它绿——而且先证明了它抓得住这个病才允许它上岗。
已加入每次发布前必跑的门禁链。

三端（电脑 / 手机 / 平板）用的是同一份界面代码，这次一起修好。

## 怎么更新

- 电脑：应用内更新会自动提示，或从 Releases 下载 `Aevistle-0.4.1-win-x64-setup.exe` 覆盖安装；
- 安卓手机/平板：下载 `Aevistle-0.4.1.apk` 覆盖安装即可，数据不受影响。
