# Aevistle

**真的会准时到的定时邮件提醒。**

写好一封邮件——可以带文件、图片、压缩包——Aevistle 负责按时发出去，窗口关着
也照发。发一次、每个工作日 09:00、每月 1 号，或者你自己写的任意 cron 表达式
都行。它认得你的法定节假日，周一的周报不会发到一个没人上班的周一去。
Windows 和安卓是同一个应用，不用注册账号，没有服务器，不收集任何数据。

*每周五的周报。每月 1 号的账单。凌晨零点的生日祝福，那会儿你在睡觉。*

## 为什么会有这个东西

哪个邮件客户端都能发邮件，但几乎没有哪个能向你保证：下周二早上 07:00，
带着正确的附件，把这封信发出去——不管你有没有想起来，也不管应用开着没开着。

Aevistle 首先要做到的就是这个承诺。不用注册账号——它连的是你本来就有的
SMTP 服务器（Gmail、Outlook、QQ 邮箱、163、公司自建的服务器），然后把信发出去。
收信功能也有，但默认不会来烦你，你不主动打开它就当它不存在：给某个账号配上
IMAP 服务器，Aevistle 就会同步出一个统一收件箱，自动把验证码和登录链接挑出来，
其余邮件一概不动。

**大家都拿它来** 每周五 17:00 发周报 · 作业截止前一晚提醒全班 · 每月 1 号寄账单 · 半夜十二点自动送出生日祝福 · 每 30 天催一次房租 · 把跟进邮件排到早上而不是凌晨两点送达 · 验证码一到就能直接拿到，不用来回切换应用。

**这些情况可能不适合你**：想要一个功能齐全的邮件客户端——不做文件夹管理、不支持推送式 IDLE 同步、不支持服务器端删除，这些都是故意不做的——需要带追踪像素和打开率的营销工具，或者希望设备关机后还有人替你继续发。Aevistle 用**你自己的**机器、**你自己的**邮箱收发信——这正是它不需要注册、也不收集任何东西的原因。

## 它能做什么

| | |
|---|---|
| 📮 **现在发，或者定时发** | 最重要的两个按钮永远钉在写信界面底部，任何窗口尺寸下都不用滚动去找发送键。发送时间就在旁边，默认填好**下一个整点**而不是留空；它还会跟着重复规则换控件：一次性任务给「日期 + 时间」，每天/每周/每月/每年给「时间」——那才是这四种规则真正据以触发的字段——而 cron 干脆不给编辑框，因为表达式本身就是规则。 |
| 📥 **可选的收件功能** | 为账户打开 IMAP，Aevistle 会自动填好服务器、保存前先测通，然后把所有账户的邮件汇总成一个收件箱——可以整体看，也可以只看某一个账户，按你设定的间隔自动检查。打开一封邮件占满整个窗口，`Esc` 逐级退出；`J`/`K` 上下翻信，`Ctrl+F` 在正文里查找。收到的附件可以直接在应用内预览（图片、PDF、纯文本），也可以交给系统程序打开、另存到任意位置、或在文件管理器中定位。远程图片默认拦截，链接一律先显示真实目标再询问。 |
| 🔑 **验证码有自己的页面** | 收到的邮件里的验证码和登录链接会被自动挑出来，集中放在一个独立页面上——发件人、标题、收到时间，以及大到一眼可读的验证码本身。点卡片任意位置即可复制。通知里直接带着验证码，连邮件都不用打开；原邮件删掉了，记录也还在。 |
| 📨 **邮件直接变成提醒** | 收到的邮件里的会议、预约和截止日期会被读出来，六种语言都认，一个按钮就能变成一条定时提醒。卡片上会把**日期是从哪句话读出来的**原样贴出来，让你核对而不是让你相信；措辞本身有歧义时它也会明说。真正的会议邀请带着 `text/calendar` 部件，日期是发件方的日历写死的——那一份优先于正文猜测，**但只在 Windows 上**：安卓的收件箱不保留这类部件，只能退回读正文。宁可什么都不说：漏掉一个日期，代价是重看一遍邮件；给错一个，代价是一场开错时间的会。 |
| ⚡ **连续发送** | 一次定时任务可以把同一条消息连续发出好几遍，间隔按你设的毫秒数来——这是用来压测你自己的发信通道的，不是让你拿去群发骚扰人的。 |
| 📎 **任意附件，图片可放进正文** | 文档、图片、压缩包——只要不超过服务商的上限都行。把复制的图片直接粘贴进正文就会内嵌显示；任何图片也都可以在「作为附件」和「显示在正文里」之间随时切换。Aevistle 会显示实际上传体积，因为 base64 会把 20 MB 的文件变成 27 MB，这正是「明明没超限」却被退信的原因。 |
| 🖼️ **图片能真的看见** | 邮件里的每一张图——嵌在正文里的、作为附件带上的、从收件箱收到的——都直接显示成能看清内容的缩略图，而不是一个要靠猜的文件名。点一下就全屏：滚轮缩放、拖动平移、双击在「适应窗口」和「原始尺寸」之间切换、左右各转 90°、水平/垂直镜像、方向键翻到这封信里的下一张，并能读到像素尺寸、文件大小和格式，再另存到磁盘或复制到剪贴板。按 `Esc` 只关图片，不会顺手把底下的页面也关掉。 |
| 📆 **月历本身就是发信计划表** | 每个日期格里直接列着当天真正会发出去的东西——时间、收件人、主题。点一条就打开那条提醒，拖到另一天就改期，在空白日期上双击就以那天为准新建一条。拖动之前它会先说清楚将要发生什么：一次性任务是**这一封**挪走，重复规则则是**规则本身**改了——因为这里没有「跳过这个周二、改发周四」的单次例外表，而一个悄悄改写了周规则的拖拽，比一个拒绝执行的拖拽糟糕得多。格子按当天有多忙上色，刻度是固定的——1、2、3、5、8 封——所以同一个周二下个月还是同一个颜色。按当月最忙的一天做归一化的话，你每加一条提醒整月都会重新上色一遍，那就只是装饰而不是信息了。 |
| ⚠️ **撞在同一分钟的发送，和一个按钮** | 落在同一分钟里的提醒会在那一天上标出来。点一下就在 ±5 分钟内把它们错开，然后逐条说明**哪些没动、为什么**——cron 表达式的分钟由它自己写死，而一个会跨过午夜的挪动改的是「哪一天」，那不是几分钟的微调该有的权限。它改的是规则的时间点，也就是往后每一次都跟着变；这句话会写在确认框里，而 `Ctrl+Z` 一次把整批放回去。 |
| 🎌 **工作日由你定义** | 法定节假日、自己定义的周末、调休上班日，月历上点一下就切换某天。六个国家的固定节日一键填入，中国的国务院节假日表（含调休上班日）是抄进来的，`.ics` 能进能出。每条提醒各自决定要不要跟着日历走，而格子上会标出**哪些发送是日历挪动的**——这是唯一能回答「配了这一堆到底有没有用」的东西。「联网查询」某一年的法定日期这个功能，此前在任何一个版本里都没成功过：是应用自己的内容安全策略在拦截界面发出的请求，而失败的样子和断网一模一样。现在这个请求改由受信任的进程发出，策略一点都没放宽。 |
| 🌐 **收件人自己的工作时间** | 联系人可以带上时区和上班时间，发给他的提醒会落进**他那边**的白天，而不是你这边的——否则在上海写下的「每周一 09:00」，到洛杉矶就是凌晨三点，一周里最没人看邮件的那个钟点。它排在工作日历和免打扰时段**之后**，并且压过这两者：于是一封被放到收件人早上的信，很可能正落在你自己的夜里——这是功能在正常工作，不是出错。只看 `To:` 那一行——被抄送的人不是「要被送达」的人，一个抄送地址没资格把正文收件人的信压住。**永远不会因此扣着不发，也不会丢**：几个收件人的时间段凑不到一起，或者某个时间段本身填错了，它会说出来，然后按你设定的时间照发。编辑框下面直接把后果写成一句话——某个点的提醒实际会几点发出、那在对方那边是几点——因为这张表单上每个值看着都合理，光读回来是验不出对错的。 |
| 🗒️ **给你自己的日程摘要** | 可选：每天一封发给你自己的邮件，列出今天要发什么、未来七天有什么、以及有没有撞车。它不是藏在什么地方的后台任务——它就是你日程里一条普通的提醒，在同一个页面看得见，能暂停、能删掉，这个功能只接受这一种做法。哪个数字只是下限而不是总数，它会说出来；正文里还写着这份摘要是**什么时刻算出来的**，因为机器很可能是几小时之后才把它发出去的。 |
| 🎉 **节日祝福：只做计划，不替你发** | 选一个国家和年份，Aevistle 把那一年的法定节假日排出来给你看。你不按那个按钮，什么都不会存在；按了之后建出来的，也是普普通通、看得见的定时任务。名字相同的连续几天算**一个**节日——国庆节 10 月 1 日到 7 日是一次祝福，不是一周里七封一模一样的信。遇到国务院还没公布的年份，它退回固定日期，并注明用的是哪一份来源，而不是拿去年的农历外推然后理直气壮地错。 |
| ⌨️ **键盘，以及一份不会说谎的快捷键表** | 每个页签都有编号，每个快捷键都列出来，而这份列表是**从页签本身生成的** —— 所以它不会再像刚才那样悄悄和实际对不上。 |
| 📤 **把提醒带走** | 把定时任务导出成文件，在另一台设备上导入。文件里不含账号、服务器和密码，放进备份是安全的。 |
| 📅 **导出的是它真正会发的时刻** | 提醒的 `.ics` 导出可以写重复规则，也可以写这个应用**已经定下来的那些时刻**——节假日顺延和免打扰时段都已经算进去了。这两者是故意会不一致的：「每个工作日 09:00」是一条正确的规则，但当日历把 10 月 1 日那一封挪到 8 号之后，它就是一份错误的日程表，而订阅方读到的将是 Aevistle 已经决定不执行的计划。**限制就摆在这里说清楚**：Outlook、Thunderbird 和 Apple 日历可以订阅保存下来的文件；Google 日历不行——它只读公网地址，而这个应用没有服务器可以挂一个。算好的清单也会过期，它只能覆盖到已经算出来的那些时刻为止，所以这是一个选项而不是默认行为。 |
| ✒️ **不引入富文本编辑器的排版** | 加粗、斜体、代码、链接、列表、引用，以 Markdown 插进同一个纯文本框；发送时渲染成邮件安全的 HTML，所以收件人看到的是排版，不是星号。 |
| 🔤 **模板变量，包括日历变量** | `{{name}}`、`{{email}}` 以及你自己给联系人加的字段，按收件人逐封填好，副本里不带 Cc 和 Bcc——群发是四十封各自的私信，不是一个把四十个人拉在一起的会话。除此之外，`{{nextWorkday}}`、`{{prevWorkday}}`、`{{holiday}}`、`{{nextHoliday}}`、`{{nextDayOff}}`、`{{daysToNextHoliday}}`、`{{workdaysLeftThisWeek}}`、`{{workdaysLeftThisMonth}}` 读的正是决定这封信**什么时候发**的那本工作日历，在发送时才解析——于是被日历挪到周一的提醒，不会还写着「明天见」。故意没有 `{{isWorkday}}`：它必须渲染成一个词，而这一层根本不知道这封信是用哪种语言写的。填不上的变量原样留着，不会被悄悄清空。 |
| 🔍 **搜到你想搜的地方** | 收件箱搜索可只按发件人、主题或正文摘要来筛 —— 找一个人时，笼统搜索会把每一封提到他名字的营销邮件都翻出来。 |
| 👆 **手机上可以滑动** | 左右滑动一封邮件即可移除或切换已读。**故意不包含服务器端删除**：那个不可撤销，不该藏在一个手势后面。 |
| 📊 **看得出到底发没发** | 每条计划都显示上次发送时间、成功还是失败、已经发了几次。一次性提醒发完自动进「已完成」页签，不再留在列表里装作还在等。 |
| 🗑️ **删除是真的删除** | 分成两个动作，因为本来就是两件事：从 Aevistle 移除（可从回收站恢复，保留 7 天），或从邮箱服务器上删除（不可撤销，界面会明说）。 |
| ✍️ **专注写作** | `F9` 把除正文以外的一切收起来，正文框拿到整个窗口，`Esc` 退出。标签上实时显示字数和字节数——一个汉字是 3 字节，而服务商的大小上限算的正是字节。 |
| 🔁 **真正的重复规则** | 一次 · 每 N 分钟 · 每天 · 每周指定星期 · 每月（31 号有合理的处理规则）· 每年 · 完整的 5 段 cron。 |
| 🔒 **附件快照** | 定一个下个月的提醒，Aevistle 会自己留一份文件副本，你后来移动或改名原文件也不会悄悄发不出去。 |
| ⏰ **关掉窗口照样发** | Windows 上留一个托盘进程；安卓用精确闹钟 + WorkManager。关窗口不等于取消提醒。 |
| 🌙 **补发策略** | 笔记本睡过去了，错过三次发送时间？可以选择只补发一次，或者直接跳过。不会一觉醒来收到三封一样的邮件。 |
| 🎲 **抖动与跳过周末** | 在一个时间窗口内随机错开发送，避免服务商把突发流量当成垃圾邮件；周末的任务可以顺延到周一。 |
| 🔐 **密码不乱跑** | 由操作系统加密——Windows 用 DPAPI，安卓用硬件级 Keystore。绝不写进设置文件，导出配置里也没有。 |
| 📂 **数据放哪你说了算** | 第一次启动就问你数据放哪，之后也能在**设置 → 数据文件夹**里改。它会把已有数据搬过去，**并修正已有定时任务里记录的附件路径**——上个月建的提醒依然能找到它的附件。 |
| 🔌 **连得上才算数** | 端口和加密方式配错了？Aevistle 会改用你的服务商同样接受的另一种组合，而不是甩一句「Unexpected socket close」，成功后还会问你要不要把这套设置存下来。每次尝试都有时间上限，所以测试按钮一定会有结果。 |
| 🩺 **把话说清楚** | 测试成功会告诉你最终连上的是哪个端口和加密方式、以及往返耗时；失败会说明原因和该改什么。发送记录里还有成功率和耗时中位数。 |
| 🌙 **免打扰时段** | 夜里的提醒攒到早上再发。手动发送永远不受影响——你人就在跟前。 |
| ⬆️ **应用内更新** | 查 GitHub Releases、下载安装包、用发布的 SHA-256 校验完整性，再交给安装程序。安卓则打开 APK 交给系统安装器。可以关掉；除了这一个请求，它不发送任何东西。**安卓上这个检查在此前发布的任何一个版本里都没有工作过**——拦住邮件正文去开 socket 的那条内容安全策略，把更新请求也一并拒了，而报出来的错和「没网」完全一样。现在这个请求改从受信任的进程发出，白名单钉的是**主机加路径**，而不是把策略放宽。 |
| 🌍 **六种语言** | English、简体中文、Français、Español、Русский、العربية——阿拉伯语是完整的从右到左布局，不是把文字翻译一下了事。 |
| 🎨 **六套视觉风格，不是六种色调** | Aurora、Graphite、Paper、Midnight、Nordic、高对比度，在**设置 → 外观**里点预览卡片就能换。风格不等于换个颜色：每一套还会重新调圆角、行高、以及允许存在多少阴影——正因如此 Graphite 看着才像另一个软件，而不是同一个软件刷成了灰色。每一套都有**真正的**亮色版和暗色版，所以「跟随系统」在哪一套下都还成立。**高对比度**是唯一一套「数字就是设计」的：每一组文字与背景的对比度都过 7:1，即 WCAG AAA，连三级的时间戳、连带底色的语义色都算在内——AAA 配色通常正是在这两处悄悄放弃的。它的描边是**故意**看得见的，亮色 3.9:1、暗色 6.3:1，高于 WCAG 对控件边界要求的 3:1。风格之外还有：亮色/暗色跟随系统或手动锁定，七种主题色——每套风格是把它们重新调过而不是把选择权收走，所以切到高对比度时你选的那个颜色还在——两种信息密度，以及按文种分开挑的字体：中文用宋体，西文与标点用 Times New Roman。 |

| Android 7.0+ | `Aevistle-<version>.apk` | 手机和平板都能装。先在浏览器或文件管理器里允许「安装未知应用」。 |

`<version>` 就是[最新发布页](https://github.com/Aevorine/Aevistle/releases/latest)上写的那个版本号，
顶部那个徽章读的也是同一处。这里故意不写死，免得过一阵就对不上了。

> **校验下载的文件。** 每个 Release 都会发布 `SHA256SUMS.txt`、它的分离签名
> `SHA256SUMS.txt.asc`，以及签名用的公钥：
>
> ```bash
> gpg --import aevistle-public-key.asc
> gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt
> sha256sum -c SHA256SUMS.txt
> ```
>
> 只对校验和能证明文件传输完整；对签名才能证明它出自本项目的密钥。
> 指纹写在 [SECURITY.md](../SECURITY.md)。

> Windows SmartScreen 会提示「未知发布者」。没有购买代码签名证书的软件就是这个样子，
> 选 **更多信息 → 仍要运行**；不放心的话，先对一下 Release 页面上的 SHA-256 校验值。

## 隐私

Aevistle 没有服务器。不用注册账号，不采集任何统计数据，不上报崩溃信息。

会离开你设备的东西是一份固定的短清单，除此之外没有别的：

1. **连接你自己的邮件服务商的那条 SMTP 连接**——你写的信，发到你配置的邮箱。
2. **连接你自己的邮件服务商的那条 IMAP 连接**——只有你打开收信功能的账号才会用到，也只用来收那个账号的邮件。
3. **收到的邮件里的远程图片，仅在你主动要求加载时**——图片默认全部拦截，用占位图代替，因为远程 `<img>` 是邮件里最古老的追踪手段。加载请求本身也做了防护，不会被重定向到你自己的内网（不解析内网 IP，不跟随跳转）。
4. **检查更新**（如果你没关掉）：一个不带身份的 `GET` 请求问 `api.github.com` 最新版本是多少。不带任何账号信息、邮件内容或使用数据。在**设置 → 更新**里关掉后，应用就不会自己发起这一个请求。
5. **法定节假日表，仅在你点「联网查询」时**——一个不带身份的 `GET`，只取某一年的日期。它和检查更新都按**主机加确切路径**做白名单，也都由受信任的进程发出，而不是由渲染邮件的那一部分发出——那一部分完全没有出网能力。

关掉更新检查之后，这份清单里剩下的每一个请求，都是你按了按钮才发生的。

所有东西都在你自己的设备上：

| | Windows | 安卓 |
|---|---|---|
| 设置、定时任务、联系人、日志 | `<数据文件夹>\state.json` | 应用存储 |
| 邮箱密码 | `secrets.json`，DPAPI 加密 | Android Keystore（有硬件支持时用硬件） |
| IMAP 密码 | 同一个文件、同样的加密，跟该账号的 SMTP 密码分开存成两条 | 同一个 Keystore，单独一条 |
| 附件快照 | `<数据文件夹>\attachments\` | `<数据文件夹>/attachments` |
| 收信缓存（正文、附件） | `<数据文件夹>\inbox\`——一个有大小和保留时长上限的缓存，可以在**设置**里调整，删掉也没事，重新同步就好 | `<数据文件夹>/inbox` |

数据文件夹默认在 Windows 的 `%APPDATA%\Aevistle`、安卓的应用私有存储，
**设置 → 数据文件夹**可以把它挪到任何你能写入的位置。
安卓上只能在系统真正允许应用写入的存储卷之间选（私有 / 共享 / SD 卡），
因为通过文档选择器选的目录，几小时后后台发送任务根本打不开。

有两样东西是**故意**不跟着搬的：密码（它是按你的操作系统账户加密的，
搬到别处也解不开），以及安卓上的闹钟数据（这样拔掉 SD 卡也不会导致提醒不发）。

导出配置永远不含密码。

## 安全

威胁模型、具体做了哪些加固、以及怎么报告漏洞，都在
**[SECURITY.md](../SECURITY.md)**。

简单说：渲染进程完全没有 Node 权限，开启了上下文隔离和严格 CSP；
任何要写进邮件头的字符串，只要含有换行符就直接拒绝（开放中继就是这么来的）；
TLS 证书默认强制校验，除非你自己在某个账号上明确关掉；
收到的邮件的 HTML 会先在主进程里按严格白名单做净化，才交给渲染进程，
并且在一个沙箱 iframe 里渲染，不管什么情况都不允许执行脚本；
安卓的闹钟接收器没有导出，别的应用没法让 Aevistle 替它发邮件。

这些你都可以自己验：

```bash
npm run audit:self
```

21 项检查，大白话输出，有问题就返回退出码 1。

## 从源码构建

**环境要求**——Node.js 20+；要打安卓包还需要 JDK 17+ 和 Android SDK
（platform 36、build-tools 35 以上）。`npm run build:android` 会自动找出
已安装但没进 PATH 的 JDK 和 SDK，所以不设 `JAVA_HOME` 也行。

```bash
git clone https://github.com/Aevorine/Aevistle.git
cd Aevistle
npm install
```

| 想干什么 | 命令 |
|---|---|
| 在浏览器里跑（不能发信，其余全是真的） | `npm run dev` |
| 类型检查 | `npm run typecheck` |
| 安全自检 | `npm run audit:self` |
| 跑桌面版 | `npm start` |
| 打 Windows 安装包 | `npm run dist:win` |
| 打安卓 APK | `npm run build:android` |

安卓正式签名读 `~/.aevistle/keystore.properties` 或 `AEVISTLE_KEYSTORE*`
环境变量。两者都没有时会退回 debug 签名，**依然能装上**，只是不是发布用的那把钥匙。

## 它是怎么搭起来的

一套 React + TypeScript 界面，两个原生外壳。

```
src/core/        与平台无关：领域模型、重复规则引擎、校验、SMTP 服务商预设
                 —— 不碰 DOM、不碰 Node、不碰安卓
src/             React 界面（六语言、六套视觉风格，每套都有真正的亮色与暗色）
    ↓ PlatformBridge —— 界面与操作系统之间唯一的接缝
electron/        Windows：nodemailer + imapflow、DPAPI 密码存储、托盘、
                 混合轮询/精确调度器、收信 HTML 净化
android/         安卓：JavaMail（收发信）、Keystore、AlarmManager + WorkManager
```

重复规则引擎**只**用 TypeScript 写。它预先算出一串绝对时间戳，
各平台的调度器只需要回答「到 T 时刻叫醒我」——于是所有日历规则
（闰年、小月、夏令时、跳过周末）只存在一份、只用一种语言写，
而且不用开模拟器就能测。

更多细节见 **[ARCHITECTURE.md](ARCHITECTURE.md)**。
